# Bodega Florio

Sitio web institucional y experiencial de Bodega Florio, ubicada en Maipú, Mendoza. El sitio presenta la bodega, su propuesta de enoturismo y sus vinos, y permite gestionar reservas y contacto.

## Stack

- React + Vite + TypeScript
- Deploy en Vercel

## Scripts

| Comando                | Descripción                                    |
| ---------------------- | ---------------------------------------------- |
| `npm run dev`          | Levanta el servidor de desarrollo              |
| `npm run build`        | Compila TypeScript y genera el build en `dist` |
| `npm run preview`      | Sirve localmente el build de producción        |
| `npm run lint`         | Analiza el código con oxlint                   |
| `npm run format`       | Formatea el código con Prettier                |
| `npm run format:check` | Verifica el formato sin modificar archivos     |
